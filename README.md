# EELab-1A Project
Technion Bachelor's degree project - Electrical Engineering Lab 1A
A full functional interactive game implemented fully in systemVerilog, made to run on a DE-10 board. 
A super-mario-like game including sound effects and visuals on a VGA screen,using a keyboard controller. 
The game has multiple enemies, multiple levels and even cheat codes.
